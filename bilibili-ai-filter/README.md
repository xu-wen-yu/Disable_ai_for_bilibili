# Bilibili AI 视频屏蔽插件

一款智能识别并屏蔽 Bilibili 网页版中 AI 生成视频的浏览器扩展插件。

## 功能特性

### 核心功能

- **智能识别**：通过关键词匹配技术，自动识别视频标题、标签、简介中的 AI 相关内容
- **灵活屏蔽**：支持「完全隐藏」和「显示提示」两种屏蔽模式
- **自定义关键词**：内置默认关键词库，支持用户添加、删除个性化关键词
- **白名单管理**：支持将信任的 UP 主或特定视频加入白名单，跳过屏蔽
- **屏蔽记录**：详细记录所有被屏蔽的视频信息，支持查看和管理

### 辅助功能

- **多页面适配**：兼容首页、推荐页、搜索页、UP 主主页、播放页、收藏夹等页面
- **静默运行**：后台自动运行，不打扰正常浏览体验
- **性能优化**：轻量级设计，占用内存小，识别速度快
- **自动同步**：设置数据自动同步至云端，多设备共享配置

## 安装指南

### 系统要求

- Microsoft Edge 浏览器（基于 Chromium 内核的最新稳定版）
- 或 Chrome 浏览器（版本 88 及以上）
- 其他基于 Chromium 内核的浏览器（理论支持）

### 安装步骤

#### 方法一：开发者模式安装（推荐用于测试）

1. 下载插件压缩包并解压到本地目录
2. 打开 Edge 浏览器，访问 `edge://extensions/`
3. 在页面右上角开启「开发者模式」开关
4. 点击「加载已解压的扩展程序」按钮
5. 选择插件解压后的文件夹（`bilibili-ai-filter`）
6. 确认插件已成功加载，图标将显示在浏览器工具栏

#### 方法二：打包安装

1. 在扩展页面点击「打包扩展程序」
2. 选择插件文件夹
3. 生成 `.crx` 文件
4. 将 `.crx` 文件拖入扩展页面完成安装

### 验证安装

1. 访问哔哩哔哩官网（https://www.bilibili.com）
2. 点击浏览器工具栏的插件图标
3. 确认弹出设置页面正常显示
4. 检查全局开关是否处于开启状态

## 使用说明

### 基础操作

#### 启用/禁用插件

- 点击插件图标，将全局开关设置为「开」或「关」
- 关闭插件后，所有 AI 生成视频将恢复正常显示

#### 管理关键词

**添加关键词**

1. 在设置页面找到「AI 关键词管理」区域
2. 在输入框中输入关键词（支持回车键快速添加）
3. 点击「添加」按钮或按回车
4. 提示「关键词添加成功」即完成

**删除关键词**

1. 在关键词列表中找到要删除的关键词
2. 点击关键词右侧的「×」按钮
3. 提示「已删除关键词」即完成

**默认关键词**

插件内置以下默认关键词：

- AI生成
- AI绘图
- AI配音
- AI合成
- AI脚本
- AI动画
- 人工智能
- AI翻唱
- AI演唱
- AI虚拟主播

### 屏蔽模式说明

#### 模式一：完全隐藏（默认）

- 列表页中的 AI 生成视频将被完全隐藏
- 不显示视频缩略图、标题、UP 主信息
- 页面布局自动调整，其他视频上移

#### 模式二：显示提示

- AI 生成视频正常显示
- 视频上覆盖半透明遮罩层
- 显示「已屏蔽 AI 生成视频」提示
- 提供「查看详情」和「取消屏蔽」按钮

### 播放页屏蔽

- 当播放 AI 生成视频时，视频将自动停止播放
- 显示全屏屏蔽提示，包含视频信息和屏蔽原因
- 可选择「关闭提示」继续播放，或「取消屏蔽」解除限制

### 白名单管理

#### 添加 UP 主到白名单

1. 点击设置页面的「白名单管理」按钮
2. 在输入框中输入 UP 主名称或 UID
3. 多个 UP 主用逗号分隔
4. 点击确认完成添加

#### 添加视频到白名单

1. 在播放页点击插件图标
2. 选择「将当前视频加入白名单」
3. 确认添加成功

#### 管理白名单

- 查看当前白名单列表
- 删除单个白名单项
- 白名单内视频不会被屏蔽

### 屏蔽记录

#### 查看屏蔽记录

1. 点击设置页面的「查看屏蔽记录」按钮
2. 查看所有被屏蔽视频的列表
3. 记录包含：视频标题、UP 主、屏蔽时间、屏蔽原因

#### 管理屏蔽记录

- **取消屏蔽**：点击单条记录的「取消屏蔽」按钮
- **清空记录**：点击「清空所有记录」按钮
- **取消屏蔽后**：视频将在刷新页面后恢复正常显示

## 技术架构

### 文件结构

```
bilibili-ai-filter/
├── manifest.json          # 插件配置文件
├── background.js          # 后台服务脚本
├── content.js             # 内容脚本（核心逻辑）
├── content-script.js      # 简化版内容脚本
├── popup.html             # 弹出设置页面
├── popup.js               # 设置页面逻辑
├── popup.css              # 设置页面样式
├── content-style.css      # 内容页样式
└── icons/                # 图标资源
    ├── icon16.png
    ├── icon48.png
    └── icon128.png
```

### 核心技术

- **JavaScript (ES6+)**：核心开发语言
- **Chrome Extension API**：扩展功能接口
- **MutationObserver**：页面动态内容监控
- **chrome.storage**：本地数据存储

### 页面 DOM 选择器

插件通过 CSS 选择器获取页面元素，支持多种选择器以适应不同页面版本：

- **首页/推荐页**：`bili-video-card`、`video-card`
- **搜索页**：`video-item`、`bili-video-item`
- **UP 主主页**：`small-item`、`user-video-list`
- **播放页**：`#viewbox_report h1`、`.video-title`

## 隐私说明

- **本地运行**：所有处理逻辑在本地浏览器执行
- **数据安全**：不收集、不上传用户个人信息
- **无追踪**：不记录用户浏览历史或账号信息
- **透明操作**：仅修改页面显示，不改动网页源代码

## 常见问题

### Q1：插件安装后未生效？

**解决方案**：

1. 确认已在扩展页面开启插件
2. 检查是否访问的是 `www.bilibili.com` 而非其他域名
3. 刷新 Bilibili 页面
4. 确认全局开关处于开启状态

### Q2：部分 AI 视频未被识别？

**可能原因**：

- 该视频的标题、标签、简介中不包含任何关键词
- 视频使用了 AI 生成但未在元数据中标注

**解决方案**：

1. 在设置中添加相关关键词
2. 手动将该视频加入白名单
3. 反馈给开发者，完善关键词库

### Q3：误屏蔽了正常视频？

**解决方案**：

1. 点击插件图标，将视频 UP 主或该视频加入白名单
2. 在屏蔽记录中取消屏蔽该视频
3. 反馈给开发者，优化识别算法

### Q4：插件占用内存过大？

**优化建议**：

1. 定期清理屏蔽记录
2. 控制关键词数量（建议不超过 50 个）
3. 不需要的插件可暂时关闭

### Q5：页面样式异常？

**解决方案**：

1. 刷新页面
2. 清除浏览器缓存后重新加载
3. 重新安装插件

### Q6：如何更新插件？

**开发者模式安装**：

1. 用新版本替换插件文件夹
2. 在扩展页面点击「重新加载」按钮

**打包安装**：

1. 等待开发者发布新版本
2. 下载新版本并重新安装
