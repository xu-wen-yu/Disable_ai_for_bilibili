# Bilibili AI 视频屏蔽插件规格说明

## 一、为什么需要这个插件

随着 AI 生成技术的快速发展，Bilibili 平台上出现了大量 AI 生成的视频内容（包括 AI 绘图、AI 配音、AI 合成画面、AI 脚本等）。部分用户希望过滤掉这些 AI 生成内容，只观看真人创作的视频。本插件旨在帮助用户自动识别并屏蔽 Bilibili 网页版中的 AI 生成视频，提供更纯净的浏览体验。

## 二、核心功能要求

### 2.1 识别功能

系统应能够精准识别 Bilibili 网页版各页面中的 AI 生成视频：

**识别维度：**
- 视频标题包含 AI 相关关键词（"AI 生成"、"AI 绘图"、"AI 配音"、"AI 合成"、"AI 脚本"、"AI 动画" 等）
- 视频简介包含 AI 相关标识
- 视频标签包含 AI 相关关键词
- 播放页视频描述信息中的 AI 相关标识

**适配页面：**
- 首页推荐区
- 搜索结果页
- UP 主主页视频列表
- 播放页
- 收藏夹页面

**识别优先级：**
1. 优先使用关键词匹配（标题、标签、简介）
2. 可扩展为关键词 + 特征识别双重模式

### 2.2 屏蔽功能

**列表页屏蔽：**
- 自动隐藏识别到的 AI 生成视频
- 不显示视频缩略图、标题、UP 主信息
- 提供"显示屏蔽记录"入口

**播放页屏蔽：**
- 自动停止视频播放
- 显示"已屏蔽 AI 生成视频"提示
- 提供查看详情或取消屏蔽选项

### 2.3 基础设置

**三个核心设置项：**

1. **全局屏蔽开关**
   - 类型：布尔开关
   - 默认值：开启
   - 功能：控制插件是否启用 AI 视频屏蔽

2. **自定义 AI 关键词**
   - 类型：字符串数组
   - 默认值：["AI 生成", "AI 绘图", "AI 配音", "AI 合成", "AI 脚本", "AI 动画"]
   - 功能：支持用户添加/删除关键词

3. **屏蔽模式选择**
   - 类型：枚举（"完全隐藏" | "显示提示"）
   - 默认值："完全隐藏"
   - 功能：
     - "完全隐藏"：列表页不显示视频
     - "显示提示"：显示视频但标记为 AI 生成，无法播放

### 2.4 辅助功能

**白名单功能：**
- 支持添加指定 UP 主到白名单
- 支持添加指定视频到白名单
- 白名单内视频不受屏蔽影响
- 随时可添加/删除白名单内容

**屏蔽记录：**
- 记录被屏蔽的视频信息（标题、UP 主、发布时间、屏蔽原因）
- 支持查看屏蔽记录列表
- 支持从屏蔽记录中取消屏蔽单个视频
- 支持清空所有屏蔽记录

**自动更新适配：**
- 监听 Bilibili 页面结构变化
- 自动检测页面更新并适配选择器
- 记录适配日志便于排查问题

### 2.5 兼容性要求

**浏览器兼容性：**
- Microsoft Edge 浏览器最新稳定版（基于 Chromium）
- 遵循 Chromium 扩展开发标准

**页面兼容性：**
- 首页（homepage）
- 推荐页（recommend）
- 搜索结果页（search）
- UP 主主页（space）
- 播放页（video）
- 收藏夹（favorites）

**功能兼容性：**
- 不影响视频加载速度
- 不影响弹幕功能
- 不影响评论功能
- 不影响播放器正常功能
- 不与 Bilibili 本身功能冲突

### 2.6 稳定性要求

**性能要求：**
- 识别响应速度 ≤ 1 秒
- 插件占用内存 ≤ 100MB
- 安装包体积 ≤ 5MB

**可靠性要求：**
- 无误屏蔽（非 AI 生成视频不被屏蔽）
- 无漏屏蔽（AI 生成视频可被识别）
- 后台静默运行，无弹窗骚扰
- 关闭插件后可恢复正常浏览

**隐私要求：**
- 不修改 Bilibili 网页原有代码
- 不收集用户个人信息
- 不上传用户浏览记录
- 不访问用户账号信息

## 三、技术架构

### 3.1 技术栈

- **核心语言：** JavaScript (ES6+)
- **页面结构：** HTML5
- **样式：** CSS3
- **扩展框架：** Chrome Extension API (兼容 Edge)
- **存储：** chrome.storage API

### 3.2 文件结构

```
bilibili-ai-filter/
├── manifest.json          # 扩展配置文件
├── popup.html            # 弹出设置页面
├── popup.js              # 弹出页面逻辑
├── popup.css             # 弹出页面样式
├── content.js            # 内容脚本（注入页面）
├── background.js         # 后台脚本
├── icons/                # 图标资源
│   ├── icon16.png
│   ├── icon32.png
│   ├── icon48.png
│   └── icon128.png
├── docs/                  # 开发文档
│   ├── README.md
│   └── TEST_REPORT.md
└── SPEC.md               # 规格说明
```

### 3.3 核心模块

**manifest.json**
- 定义扩展元数据
- 声明权限
- 配置 content_scripts 注入规则
- 配置 browser_action

**content.js（内容脚本）**
- DOM 元素解析
- 视频信息提取
- AI 关键词匹配
- 视频屏蔽处理
- 与 background.js 通信

**background.js（后台脚本）**
- 管理插件状态
- 处理设置存储
- 响应 content.js 请求
- 协调多个页面

**popup.js（弹出页面）**
- 读取和显示设置
- 处理用户交互
- 同步设置到 storage

## 五、关键词匹配算法

### 5.1 匹配策略

```javascript
// 1. 精确匹配（区分大小写）
// 2. 支持正则表达式
// 3. 全角半角兼容（可选）
```

### 5.2 匹配字段

- 标题（权重：高）
- 标签（权重：高）
- 简介（权重：中）
- UP 主名称（权重：低，仅辅助参考）

### 5.3 匹配流程

```
1. 获取视频信息（标题、标签、简介）
2. 遍历关键词列表
3. 对每个关键词进行正则匹配
4. 匹配成功则标记为 AI 生成视频
5. 执行屏蔽操作
```
